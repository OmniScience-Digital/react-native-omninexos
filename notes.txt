You build and install it like a normal Android app after prebuilding:

**Steps:**

1. Prebuild native project

   ```bash
   npx expo prebuild
   ```

2. Plug in your phone (USB debugging ON)

3. Run/install on device

   ```bash
   npx expo run:android
   ```

That will **build and install the APK automatically** on your phone.

---

**If you want a standalone APK file:**

```bash
cd android
./gradlew assembleRelease
```

APK will be here:

```
android/app/build/outputs/apk/release/app-release.apk
```

Then install manually:

```bash
adb install app-release.apk
```
